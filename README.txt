# Launcess — Website Laundry

Website statis siap deploy ke GitHub Pages.

## Isi
- `index.html` — halaman utama
- `style.css` — desain responsif tema merah & cream
- `script.js` — menu mobile
- `assets/laundry.jpg` — foto laundry yang diberikan

## Kontak
Pesanan diarahkan ke Instagram: @nnws_dinee25

## Deploy GitHub Pages
1. Upload semua isi folder ini ke repository GitHub.
2. Buka Settings → Pages.
3. Pilih branch `main` dan folder `/ (root)`.
4. Save, lalu buka URL GitHub Pages yang diberikan GitHub.
